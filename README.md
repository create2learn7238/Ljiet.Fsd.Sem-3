# 📚 Full Stack Development with JavaScript - 1


## 🎯 Course Outcomes

| CO | Description |
|----|-------------|
| **CO1** | Understand the concepts of WWW, HTTP Protocol, Client-Server architecture, and HTML. |
| **CO2** | Explore CSS features to define and apply CSS rules in Web Pages for rich User Interface. |
| **CO3** | Determine how to build responsive web design using Bootstrap. |
| **CO4** | Use JavaScript to create dynamic and interactive web applications. |

---

## 📖 Syllabus

### Unit 1: Introduction to Web and Web Design `(5%)`
- **1.1** Basics of WWW, HTTP Protocol (Features, Request & Response, Status Codes), URL, Client-Server Architecture
- **1.2** Concepts of Effective Web Design — Website Planning, Browser Compatibility, Bandwidth & Cache, Display Resolution, Look & Feel, Page Layout & Linking, Designing Effective Navigation

---

### Unit 2: HTML Structure and Core Tags `(10%)`
- **2.1** Basics of HTML — Page Structure, Building Blocks (`<html>`, `<head>`, `<title>`, `<body>`), Editors (Notepad, Notepad++, Sublime Text, VS Code)
- **2.2** Semantic & Non-Semantic Tags, Block & Inline Elements, Comments
  - **Header Tags:** `<link>` (favicon), `<script>`, `<style>`
  - **Meta Tag:** `name`, `content`, `charset`, `http-equiv`, `viewport`, `description`, `keywords`, `author`
  - **Layout & Sectioning:** `<div>`, `<span>`, `<header>`, `<footer>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<nav>`
  - **Content & Text:** `<h1>`–`<h6>`, `<p>`, `<pre>`, `<br>`, `<hr>`
  - **Hyperlink:** `<a>`
  - **Text Formatting:** `<b>`, `<strong>`, `<i>`, `<em>`, `<u>`, `<mark>`, `<del>`, `<ins>`, `<sub>`, `<sup>`, `<abbr>`
- **2.3** Media Tags (`<img>`, `<figure>`, `<figcaption>`, `<audio>`, `<video>`, `<source>`), `<iframe>`, Lists (`<ul>`, `<ol>`, `<li>`), Tables (`<table>`, `<tr>`, `<td>`, `<th>`, `<thead>`, `<tbody>`, `<tfoot>`, `<caption>`, `colspan`, `rowspan`)

---

### Unit 3: Forms, Graphics, and Interactive Elements in HTML `(10%)`
- **3.1** Form & Input Tags — `<form>`, `<fieldset>`, `<legend>`, `<input>`, `<textarea>`, `<button>`, `<label>`, `<datalist>`, `<select>`, `<option>`, `<optgroup>`
  - **Input Types:** `text`, `password`, `email`, `number`, `tel`, `checkbox`, `radio`, `submit`, `reset`, `button`, `file`, `hidden`, `date`, `range`, `color`
  - **Attributes:** `action`, `method`, `type`, `name`, `id`, `value`, `placeholder`, `required`, `readonly`, `disabled`, `checked`, `maxlength`, `minlength`, `step`, `min`, `max`, `multiple`, `accept`, `autocomplete`, `autofocus`, `rows`, `cols`, `selected`, `list`
- **3.2** SVG — Line, Circle, Rectangle, Logo, Polygon (Star)
- **3.3** HTML Image Maps — `<map>` and `<area>`

---

### Unit 4: Introduction to CSS `(10%)`
- **4.1** Significance of CSS, Types (Inline, Internal, External)
- **4.2** CSS Selectors — Id, Class, Attribute, Universal, Descendant, Child, Grouping, Pseudo-class, Pseudo-element; CSS Specificity
- **4.3** Background Properties, Text Properties, Font Properties, Google Fonts (`<link>` / `@import`)
- **4.4** Border, Box Model (`margin`, `padding`, `width`, `height`, `box-sizing`, `box-shadow`), Display (`inline`, `block`, `inline-block`, `none`, `flex`, `grid`), Flexbox, Grid Layout, Positioning (`static`, `relative`, `absolute`, `fixed`, `z-index`)

---

### Unit 5: CSS Effects, Animations & Responsive Design `(10%)`
- **5.1** Multiple Columns, Style Images (Rounded, Thumbnail, Responsive, Transparent), Gradients (Linear, Radial, Conic), Transformations (`rotate`, `scale`, `translate`, `skew`), Transitions, Animations (`@keyframes`)
- **5.2** CSS Variables (`:root`, `var()`), Media Queries (Syntax, Media Types)

---

### Unit 6: Introduction to Bootstrap & Utility Classes `(10%)`
- **6.1** Bootstrap Setup, Containers (Fixed, Fluid), Utility-first Classes (Spacing, Display, Colors, Sizing, Borders, Positioning, Typography, Shadows, Flex), Images, Tables
- **6.2** Grid System, Alerts, Buttons, Spinners
- **6.3** Dropdowns, Cards, Collapse, Accordion

---

### Unit 7: Bootstrap Components — Navigation & Forms `(15%)`
- **7.1** Navbar (Dropdown, Collapsible), Sidebar, Offcanvas, Carousel, Modal, Scrollspy
- **7.2** Pagination, Forms (Validations, Floating Labels)

---

### Unit 8: Core JavaScript Concepts & Functions `(5%)`
- **8.1** Basics of JavaScript & ES6, `var`/`let`/`const`, Template Literals, Data Types, Variables, Arrays & Objects, Array Methods (`push()`, `pop()`, `map()`, `filter()`, `forEach()`, `includes()`, `find()`)
- **8.2** Loops (`for`, `while`, `do...while`, `for...of`, `for...in`), Conditions (`if...else`, `switch`), Functions (declarations, expressions, arrow functions), Default Parameters, Spread & Rest Operators
- **8.3** Pop-up Boxes — `alert()`, `confirm()`, `prompt()`

---

### Unit 9: JavaScript DOM Manipulation & Events `(15%)`
- **9.1** DOM Manipulation — `document`, `getElementById`, `getElementsByClassName`, `querySelector`, `querySelectorAll`, `innerHTML`, `innerText`, `setAttribute`, `getAttribute`, `removeAttribute`, Style Manipulation
- **9.2** Event Handling — `click`, `input`, `submit`, `mouse`, `keyboard`, `addEventListener`, `event.target`, `event.type`, `event.key`, `event.preventDefault`

---

### Unit 10: Modern JavaScript — Async, Fetch, and Forms `(10%)`
- **10.1** Form Validation (required fields, regex), Form Processing, Local Storage, Session Storage
- **10.2** Asynchronous JavaScript — Promises (`.then()`, `.catch()`, `.finally()`), `async/await`
- **10.3** Fetch API for HTTP Requests to External APIs

---
